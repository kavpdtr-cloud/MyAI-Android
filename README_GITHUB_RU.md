# Мой AI — сборка Android APK через GitHub Actions

## Что включено в эту версию

- Русскоязычный чат с историей сообщений.
- Голосовой ввод и озвучивание ответов средствами Android.
- Настройка HTTPS API endpoint, API-ключа, модели чата и модели изображений.
- Прикрепление фотографий из хранилища телефона и передача их в модель через формат `image_url` (провайдер и выбранная модель должны поддерживать vision).
- Импорт документов PDF, DOCX, PPTX, XLSX, TXT и MD с извлечением текста и добавлением его к запросу.
- Генерация изображений через совместимый endpoint `/images/generations`.
- Отображение результата генерации и команда сохранения в Pictures/MyAI.
- Хранение API-ключа с использованием Android Keystore.
- Использование системного VPN Android: приложение не управляет VPN и не обходит ограничения провайдеров.

## Ограничения первой версии

- PDF со сканами без текстового слоя не распознаются (OCR пока не включён).
- Из документов извлекается текст; сложное форматирование, таблицы, формулы и встроенные объекты могут быть переданы не полностью.
- Для фотографий нужна vision-модель. Для генерации изображений провайдер должен реализовать OpenAI-совместимый `/images/generations` и возвращать `url` или `b64_json`.
- Разные совместимые API могут иметь несовпадающие параметры. Если провайдер не поддерживает указанный формат, потребуется адаптер под него.
- Фотографии и текст документов передаются выбранному API-провайдеру при отправке сообщения.
- Debug APK предназначен для тестирования, не является релизной публикацией.

## Сборка через GitHub

1. Создайте репозиторий GitHub, например `MyAI-Android`.
2. Распакуйте архив и загрузите **всё содержимое** папки проекта в корень репозитория, включая скрытую папку `.github`.
3. Нажмите **Commit changes**.
4. Откройте вкладку **Actions**. Workflow **«Собрать APK MyAI»** запускается при push в `main`; его также можно запустить вручную через **Run workflow**.
5. Дождитесь зелёной галочки.
6. Откройте завершённый запуск и скачайте артефакт **MyAI-debug-apk** в разделе Artifacts.
7. Распакуйте скачанный ZIP. Внутри будет `app-debug.apk`.
8. Перенесите APK на Android-телефон и установите его. При необходимости разрешите установку приложений из выбранного источника.

## Инструменты сборки

- JDK 17
- Gradle 8.9
- Android Gradle Plugin 8.7.3
- Android SDK Platform 35

GitHub Actions устанавливает инструменты в облаке. Android Studio и локальный Gradle на компьютере не нужны.

## Настройка API в приложении

Откройте шестерёнку и укажите:

- HTTPS-адрес API, например `https://api.openai.com/v1` (только если этот API доступен вам и разрешён провайдером).
- API-ключ выбранного провайдера.
- Модель чата с поддержкой vision, если планируется анализ фотографий.
- Модель генерации изображений, поддерживающую endpoint `/images/generations`.

API обычно оплачивается отдельно от подписки ChatGPT. Не публикуйте ключ в GitHub, сообщениях или скриншотах. В этой версии ключ хранится на устройстве в Android Keystore.
